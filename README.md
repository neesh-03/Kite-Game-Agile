# Kite Clash

Kite Clash is an interactive browser-based arcade game inspired by traditional kite-flying festivals and the simple, engaging mechanics of games such as Fruit Ninja. The game combines familiar arcade-style interaction with a kite-flying theme, progressive levels, scoring, obstacles, and increasing difficulty.

## Project Overview

The objective of the game is to control a kite, collect targets, avoid obstacles, and compete against opponent kites across multiple levels. Each level introduces additional gameplay elements and gradually increases the difficulty.

The game is designed as a lightweight interactive web application and can be run directly in a modern web browser without requiring any external software or installation.

## Features

* Interactive kite-based gameplay
* Five progressive levels
* Increasing difficulty across levels
* Score and lives system
* Timer-based challenges
* Collectible wind rings
* Moving obstacles
* Opponent kites
* Kite-string cutting mechanic
* Changing wind conditions
* Combo scoring system
* Level progression and unlocking
* Responsive interface
* Built-in visual effects and animations

## Levels

### Level 1 — First Flight

Players learn the basic kite controls while collecting wind rings within a limited time.

### Level 2 — Crowded Skies

Moving obstacles and additional kites are introduced, requiring greater control and precision.

### Level 3 — Cut the String

Players compete against opponent kites and earn points by cutting their kite strings.

### Level 4 — Wild Wind

Changing wind conditions affect kite movement while multiple opponents and obstacles increase the challenge.

### Level 5 — Festival Finale

The final level combines the previously introduced mechanics into a more challenging arcade-style experience.

## Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

No external frameworks or libraries are required.

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a modern web browser.
3. Start the game from the main menu.
4. Use the available keyboard or mouse controls to operate the kite.

## Project Objective

The project demonstrates the development of an interactive browser-based game using fundamental web technologies. It focuses on user interaction, game logic, visual feedback, level progression, and responsive interface design.
